# brightside

เว็บแอพติดตามการออกกำลังกายรายวัน (Vite + React) ธีมขาวคลีน รองรับมือถือ ใช้ออฟไลน์ได้ — ข้อมูลเก็บใน localStorage ของเครื่อง

## ฟีเจอร์
- **หน้าแรก** ชื่อ น้ำหนัก ส่วนสูง → BMI (เกณฑ์เอเชีย) → เป้าหมาย/ระดับ/วันฝึก/อุปกรณ์/น้ำหนักเป้าหมาย → ออกแบบโปรแกรมอัตโนมัติ หรือใช้ตาราง PPL 5 วัน
- **วันนี้** เช็กลิสต์เซ็ต บันทึกน้ำหนัก/ครั้ง · วอร์มอัพ · จับเวลาพักและท่านับเวลา · แนะนำน้ำหนักเริ่มต้นของแต่ละท่าตามน้ำหนักตัว/BMI/เพศ/อายุ/ระดับ (แสดงเป็น placeholder ในช่องน้ำหนัก เฉพาะท่าที่ยังไม่เคยบันทึก) · แนะนำเพิ่มน้ำหนักเมื่อทำครบทุกเซ็ตที่ครั้งสูงสุด · ข้ามวัน · สัปดาห์เบา (ทุก 6 สัปดาห์) · **อาหารและน้ำ**: เป้าแคลอรี่/โปรตีน/คาร์บ/ไขมัน/น้ำรายบุคคล (ตาม BMI เกณฑ์เอเชีย อายุ เพศ เป้าหมาย วันฝึก/วันพัก) ฐานข้อมูลอาหาร 380+ เมนู (อาหารไทย ก๋วยเตี๋ยว ผลไม้ ขนม เครื่องดื่ม น้ำอัดลม/ชา/กาแฟ ฟาสต์ฟู้ด) ค้นหาได้หลายคำ/ภาษาอังกฤษพื้นฐาน · แตะอาหารแล้วเลือกปริมาณตามหน่วยจริง (กี่ฟอง ครึ่งชาม) หรือ **ชั่งเป็นกรัม** (จำโหมดที่ใช้ล่าสุด · เครื่องปรุงใส่เป็นกรัมได้) · "กรอกเอง" ใส่ค่าต่อ 100 g ตามฉลาก + น้ำหนักที่ชั่ง และบันทึกเป็น "เมนูของฉัน" ใช้ซ้ำได้ · "เพิ่มรายละเอียด" เลือกน้ำมัน เครื่องปรุง ผงปรุงรส ส่วนเสริมพร้อมจำนวนช้อนเอง · แตะรายการที่บันทึกเพื่อแก้ไข/ลบ · **โซเดียม** ของทุกเมนูและเครื่องปรุง (ค่าประมาณ) พร้อมแถบเทียบเพดาน 2,000 มก./วัน และสรุปเฉลี่ย 7 วัน · แนะนำสิ่งที่ควรกินต่อ · จำปริมาณครั้งก่อน
- **แผน** ตารางรายสัปดาห์ แก้เซ็ต/ครั้ง เพิ่ม–ลบท่า ออกแบบใหม่
- **คลัง** 164 ท่า เบสิก → มืออาชีพ (รวมท่าสำหรับผู้เริ่มต้น/ผู้สูงอายุ ยางยืด ยืดเหยียด) ค้นหา/กรองตามระดับ กลุ่มกล้ามเนื้อ อุปกรณ์ ท่าโปรด · ได้อะไร วิธีเล่น ห้ามพลาด รูป 2 เฟรม ลิงก์วิดีโอ YouTube
- **ความคืบหน้า** เทียบสัปดาห์ กราฟน้ำหนัก+เป้า สัดส่วนร่างกาย เหรียญรางวัล ปฏิทิน 12 สัปดาห์ สถิติสูงสุด ประวัติ (แตะเพื่อแก้ย้อนหลัง)
- **ฉัน** BMI เป้าแคลอรี่/โปรตีน/น้ำ ตัวอย่างมื้อ แก้โปรไฟล์ เวลาพัก ขนาดตัวอักษร (ปกติ/ใหญ่/ใหญ่มาก เฉพาะเครื่อง) สำรอง/นำเข้า/ลบข้อมูล

```
npm install
npm run dev       # พัฒนา
npm run build     # production → dist/ (มี service worker สำหรับออฟไลน์)
npm run check     # ตรวจสูตร ตัวออกแบบโปรแกรม ตรรกะโค้ช โภชนาการ ฐานข้อมูลอาหาร/หน่วย/เครื่องปรุง
npm run images    # ดึงรูปท่าใหม่ (free-exercise-db, Unlicense)
```

รูปท่าจาก [free-exercise-db](https://github.com/yuhonas/free-exercise-db) · ข้อมูลเป็นแนวทางทั่วไป ไม่ใช่คำแนะนำทางการแพทย์
